# vec-tone

基于语义向量与古典声律的文本与诗词音乐生成工具。纯前端离线即可出谱试听，支持多流派编曲、交互式五线谱播放与 WAV 音频导出，可选接入大模型进行深度意境解析。

## 核心特性

- **声律与语义生成**：结合三维情感量化与古典平水韵，自动将文本映射为五声音阶旋律与节奏。
- **多音乐流派**：支持古典中国风、现代流行 R&B、城市爵士、爆款动感等风格一键编曲。
- **交互式五线谱**：基于 abcjs 实时渲染矢量乐谱，支持音字同步高亮与随点随播。
- **双模解析架构**：默认纯前端离线运行，亦可配置大模型（如 DeepSeek）生成意境解读与节拍蓝图。
- **音频导出**：支持纯前端离线渲染导出 16-bit 44.1kHz 高保真 WAV 音频。

## 实现机制

1. **语义与声律解析**
   - **情感三维量化**：提取情绪色彩（效价）、能量张力（唤醒度）与格局意象（优势度），映射调式调性、BPM 速度与音区跨度。
   - **古典平水韵律**：基于平水韵平仄规则赋音（平长仄短），标点句读对齐乐句休止与小节线。
   - **双模解析降级**：默认使用本地规则引擎输出 32 维特征向量，可选接入大模型增强意境解读，支持无缝降级。

2. **乐理编曲与曲式结构**
   - **起承转合结构**：按经典四段曲式推进旋律（起·动机呈示、承·低区呼应、转·高区高潮、合·归根解决）。
   - **旋律对位法则**：强拍严格对齐伴奏和弦骨干音，以五声音阶平稳级进为主，大跳反向解决并配以拖腔滑音装饰。

3. **发声引擎与离线渲染**
   - **多轨音频矩阵**：基于 Web Audio 构建采样器与合成器矩阵，整合主旋律、伴奏和弦、低音与节奏声部。
   - **音谱同步交互**：基于 abcjs 实时渲染矢量五线谱，支持光标与文字毫秒级跟随高亮及点击音符随点随播。
   - **前端无损渲染**：基于 Web Audio 离线音频上下文在浏览器端直接合成导出 16-bit 44.1kHz WAV 音频。
