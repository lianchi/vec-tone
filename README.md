# vec-tone 🎵

> **语意成律，音画共鸣**<br>
> 基于语义向量与古典声律的文本与诗词音乐生成工具。纯前端离线即可出谱试听，支持多流派编曲、五线谱随点随播与高保真音频/MIDI 导出，可选接入大模型进行深度意境解析。

---

## 💡 设计理念

在自然语言处理中，文本常被映射为高维向量空间。`vec-tone` 探索将语言特征与音乐规律相结合：不仅提取文本的情感色彩与声律节奏，更遵循传统五声音阶、起承转合曲式与现代和声织体，使生成的乐曲既能忠实反映文本意境，又具备自然流畅的听感。

---

## 🧠 核心实现机制

### 1. 双模语义解析架构

系统支持本地规则引擎与云端大模型双模协作：

- **输入文本**：支持古典诗词、现代随笔或自由短句。
- **语义理解**：
  - **本地离线引擎（默认）**：
    - **情感三维量化**：提取情绪色彩（效价）、能量张力（唤醒度）与格局意象（优势度），决定宫调（明朗）或羽/商/角调（凄清苍茫），并映射速度（58 ~ 96 BPM）与音区跨度。
    - **古典平水韵**：平声（阴平/阳平）舒展悠长，赋予长音；仄声（上/去/入）顿挫跳跃，赋予短音；标点句读对应小节线、休止符与乐句终止。
    - **高维特征向量**：输出 32 维归一化向量，确保意境相近的诗句生成相似的调式走向。
  - **大模型深度增强（可选）**：
    - 服务端提供 `POST /api/compose` 接口，支持接入 DeepSeek 等兼容大模型。
    - 自动生成诗境画面解读、浪漫向量构思与逐句节拍蓝图。
    - 内置 IP 限流与超时降级机制，若未配置密钥或网络异常，无缝回退至本地算法。

### 2. 乐理与旋律编曲

- **四大音乐风格**：
  - **古典中国风**：空灵丝弦、流动琶音、句末过门加花与前倚音装饰。
  - **现代流行 R&B**：离拍切分和弦、轻盈响指与松弛律动。
  - **城市爵士**：迈步贝斯、节拍切分与摇摆鼓点。
  - **爆款动感**：四四拍动感底鼓与八分音符泵感贝斯。
- **起承转合曲式**：
  - **起（动机呈示）**：中音区平稳展开，句尾半终止，留出余味。
  - **承（呼应延展）**：在中低音区呼应前句，情绪暂歇。
  - **转（情感高潮）**：跃迁至高八度音区，情绪饱满，辅以切分律动。
  - **合（归根解决）**：旋律逐级下行，稳稳落入调式主音，圆满收韵。
- **旋律对位法则**：
  - **强拍骨干音吸附**：强拍旋律严格对应伴奏和弦内音，避免撞音。
  - **弱拍级进与跳进解决**：以五声音阶平稳级进为主；出现大跳进时反向级进解决，符合人声自然吟咏。
  - **拖腔转音**：长音字自动衍生出一字多音的柔和滑音。

### 3. 多轨发声与导出

- **立体声音响矩阵**：
  - 采用施坦威大三角钢琴多层采样，兼备高质量合成音色；
  - 配备分解伴奏、宽阔氛围垫音、扎实低音与现代打击乐组（底鼓、军鼓、踩镲）；
  - 全链路串接动态压限器与大音乐厅混响。
- **交互式矢量乐谱（随点随播）**：
  - 基于 `abcjs` 实时渲染高清矢量五线谱，演奏时光标与文字毫秒级同步高亮；
  - 乐谱中的音符与歌词汉字均支持点击，点击即刻精准定位时间轴并启动试听。
- **双格式文件导出**：
  - **高保真 WAV**：纯前端基于 Web Audio 离线渲染管道导出 16-bit 44.1kHz 无损音频，音质与网页播放完全一致；
  - **标准多轨 MIDI**：基于 `midi-writer-js` 导出包含旋律轨、伴奏轨与贝斯轨的 `.mid` 文件，便于导入专业宿主软件二次创作。

## 🖥️ 功能特性

| 模块 | 功能说明 |
| :--- | :--- |
| **诗词灵感预设** | 内置《望月怀远》、《鹿柴》、《将进酒》、《春夜喜雨》、《登高》、《水调歌头》一键体验 |
| **自由文本创作** | 支持输入任意现代文本或古典诗词，即时提取声律与情感特征，所见即所得修改出曲 |
| **四大流派配器** | 古典中国风、现代流行 R&B、城市爵士、爆款动感四大风格一键切换并即时重编曲 |
| **大模型深度解析** | 可选接入大模型接口，生成定制意境解读、向量概念与微观节拍蓝图 |
| **交互式五线谱** | 矢量乐谱渲染，支持点击音符或文字直接跳转播放进度，毫秒级音字跟随高亮 |
| **双端自适应** | 桌面端卡片控制台；移动端自适应吸底播放器，支持空格键快捷播停 |
| **高保真 WAV 下载** | 纯前端毫秒级离线渲染无损音频文件，无需网络请求或服务端合成 |
| **标准多轨 MIDI** | 一键导出标准三轨 `.mid` 文件，适配各大专业音乐制作软件 |

## 🏗️ 目录结构说明

```
vec-tone/
├── assets/
│   └── styles.css          # 全局样式与亮暗主题底色
├── components/
│   ├── Generator.vue       # 核心创作交互面板（流派切换、AI 概念、移动端底栏联动）
│   ├── PlayerCard.vue      # 音乐播放器卡片（播放/暂停、进度条拖拽、快捷键、WAV 导出）
│   ├── ScoreViewer.vue     # 矢量乐谱交互视窗（ABC 渲染、音字同步高亮、点击随点随播）
│   └── TrackInfo.vue       # 曲目元信息与意境解读折叠面板
├── logic/
│   ├── composer.ts         # 作曲主调度：起承转合编排、多轨声部装配与乐曲生成调度
│   ├── midi.ts             # 多轨标准 MIDI 编码与 Base64 转换
│   ├── player.ts           # 播放引擎：Web Audio 施坦威采样器、合成器矩阵与离线渲染
│   ├── presets.ts          # 经典古诗词灵感预设与和声配器模板库
│   ├── quantizer.ts        # 诗词音节切分、节拍守恒量化求解器与重音权重
│   ├── state.ts            # 全局响应式状态管理（Pinia-less 极简轻量状态）
│   ├── theory.ts           # 乐理模型：五声音阶、调式定义、和弦织体与音乐特征
│   ├── vectorizer.ts       # 语义引擎：情感三维量化、平水韵声律识别与向量空间
│   └── wav.ts              # 纯前端原生 AudioBuffer 转换为 PCM RIFF WAV 编码器
├── server/
│   ├── api/
│   │   └── compose.post.ts # 服务端大模型深度意境解析与节拍蓝图接口
│   └── middleware/
│       └── rate-limit.ts   # 服务端 API 全局 IP 速率限制中间件
├── types/
│   └── music.d.ts          # abcjs 与 midi-writer-js 的 TypeScript 类型扩展声明
├── pages/
│   └── index.vue           # 首页布局与主题模式切换
├── nuxt.config.ts          # Nuxt 4 配置文件
├── uno.config.ts           # UnoCSS 原子化样式规则与主题色
└── eslint.config.js        # ESLint 代码规范与格式化配置
```

## 🚀 本地开发与启动

### 环境要求
- Node.js >= 18.0.0
- pnpm >= 9.0.0

```bash
# 1. 安装依赖
pnpm install

# 2. (可选) 配置环境变量
# 复制或创建 .env 文件填入大模型配置（若不配置则全功能走纯前端本地算法）
# AI_API_KEY=your_api_key_here
# AI_BASE_URL=https://api.deepseek.com/v1
# AI_MODEL=deepseek-chat

# 3. 启动本地开发服务 (支持 HMR 热更新)
pnpm dev

# 4. 类型检查与代码校验
pnpm typecheck
pnpm lint
```

访问：`http://localhost:3000`

## ☁️ 部署说明 (推荐 Vercel)

本项目采用轻量架构，无需购买和维护云主机：

1. 将项目推送到 GitHub 仓库；
2. 在 [Vercel 仪表盘](https://vercel.com/) 导入该仓库，框架预设选择 **Nuxt.js**；
3. **(可选) 环境变量**：若需启用大模型意境分析，在项目设置中添加 `AI_API_KEY`、`AI_BASE_URL`（默认 `https://api.deepseek.com/v1`）与 `AI_MODEL`（默认 `deepseek-chat`）；
4. 点击 **Deploy** 即可一键完成部署并绑定自定义域名。
