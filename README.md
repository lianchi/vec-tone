## 💡 为什么做 vec-tone？（诞生背景与思考）

在现代人工智能技术中，自然语言可以通过 **Embedding（嵌入模型）** 映射为一个由高维浮点数构成的向量空间（如 512 维、1536 维）。既然语义在数理几何上可以被向量化，**那么我们为什么不能把自然语言向量化为音符与乐曲呢？**

然而，如果只是死板地把高维浮点数粗暴对应到 0~127 的 MIDI 音高上，人耳听到的必然是毫无节拍、杂乱无章的“现代十二音体系噪音”。

为了解决**“既要忠实反映向量语义，又要确保乐曲足够动听”**的矛盾，`vec-tone` 采用了一套兼具东方美学、古典音韵学与现代流行和声的创新实现思路。

## 🧠 核心实现思路深度解析

### 1. 无 LLM / 零外部 API 下的自然语言语义理解

很多开发者认为“理解自然语言必须调用几十亿参数的云端大模型”。但在不需要复杂长文本对话、追求**毫秒级响应、零使用成本、隐私安全与高稳定性**的工具型 Web 应用中，传统统计自然语言处理（Statistical NLP）与符号学特征工程往往具有巨大的优势：

```
                    ┌──────────────────────────────┐
                    │    自然语言 / 古诗词输入      │
                    └──────────────┬───────────────┘
                                   ▼
        ┌──────────────────────────┴──────────────────────────┐
        ▼                                                     ▼
【VAD 心理学情感三维模型】                              【古典声律与字词音韵】
 • Valence (效价): 喜乐晴朗 vs 哀怨清冷                 • 平水韵提取: 平声 (舒展) vs 仄声 (短促)
 • Arousal (能量): 激越跌宕 vs 禅寂安详                 • 句读与对仗: 逗号/句号 ──> 乐句终止式
 • Dominance (格局): 天地苍茫 vs 帘外纤巧               • 局部字符滑窗特征与意象聚类
        └──────────────────────────┬──────────────────────────┘
                                   ▼
                    ┌──────────────────────────────┐
                    │  32 维归一化语义向量空间      │
                    │  (支持余弦相似度 Cosine Sim)  │
                    └──────────────┬───────────────┘
                                   ▼
                    ┌──────────────────────────────┐
                    │  乐理映射引擎 (调式/和弦/旋律) │
                    └──────────────────────────────┘
```

1. **VAD 心理学情感三维模型（情绪色彩量化）**：
   - 提取文本的词汇情绪分布，计算三大经典轴向：
     - **Valence（情绪效价，-1.0 ~ +1.0）**：量化喜悲色彩。直接决定音乐采用**明朗的宫调式（类似大调）**还是**凄美的羽调式（类似小调）**；
     - **Arousal（唤醒度，0.1 ~ 0.95）**：量化文本的能量张力。直接映射为乐曲的 **BPM 节拍速度（58 ~ 96）** 与音符密集程度；
     - **Dominance（意象气象，0.2 ~ 0.9）**：量化文本意境是“壮阔雄浑”（乾坤/天地/黄河）还是“纤巧温婉”（细雨/微风/阶前），映射低音声部与音区八度。
2. **古典诗词平水韵声律学（平仄即节拍）**：
   - “诗歌本一家”，古诗词本身即具有强大的音律规范。
   - **平声（阴平/阳平）**：发声舒展悠长，算法自动赋予较长时值（四分音符 `4n`、二分音符 `2n`）；
   - **仄声（上/去/入）**：发声短促顿挫，算法自动赋予跳跃时值（八分音符 `8n`、附点重音）；
   - **句读书写与断句**：诗词的逗号、句号自然对应乐理上的**小节线、呼吸休止符（Rest）与主音终止式（Cadence）**。
3. **确定性高维嵌入空间与余弦相似度度量**：
   - 将情感密度、音律特征、局部字符滑窗哈希组合为 **32 维 L2 归一化向量**；
   - 保证几何距离守恒：两句意境相近的诗句（如《望月怀远》与《月是故乡明》）在向量空间内的余弦相似度极高（>85%），从而在数学上确保**语义相似的诗句生成的调式、和声与风格走向必然相近**。

### 2. 乐理与旋律工程：“五声为骨，流行和声为肉，起承转合为脉”

许多文本转音乐工具听感单调机械的原因在于“字对音死板对应”或“随机音高跳跃”。`vec-tone` 借鉴了华语中国风巅峰（如周杰伦《青花瓷》《东风破》、周深《大鱼》）的核心乐理与制作编曲逻辑：

- **曲式架构（起、承、转、合宏观呼吸感）**：
  - **起（Phrase 1 · 动机呈示）**：中音区舒展展开，句尾半终止（Half Cadence）在属音/商音，留足想象与回味空间；
  - **承（Phrase 2 · 呼应延展）**：在中低音区呼应前句，情绪暂歇（Imperfect Cadence）；
  - **转（Phrase 3 · 情感高潮）**：旋律跳跃至**高八度高音区（Climax Register）**，副歌情绪迸发，辅以切分律动；
  - **合（Phrase 4 · 归根解决）**：如同大江归海、落霞孤鹜，旋律优雅逐级下行，在句尾稳稳落入调式主音（Authentic Cadence），达到圆满收韵。
- **旋律微观法则（骨干音落地 + 级进流动 + 反向跳进解决）**：
  - **强拍骨干音吸附**：在第 1、第 3 强拍上，旋律音符严格吸附于当前伴奏和弦的三和弦内音（Chord Tones），彻底消除撞音刺耳感；
  - **弱拍级进与小跳解决**：字与字之间以五声音阶平稳级进为主（±1 阶）；一旦产生跳进（≥2 阶），后续音符强制执行生理性反向级进解决，宛如人声自然吟咏；
  - **古典声律咬合**：平声（阴平/阳平）赋予舒缓上升或持留，仄声（上/去/入）赋予铿锵下行与短促顿挫。
- **律动呼吸与句间加花（Fills）**：
  - 针对五言诗（2-1-2 律动）与七言诗（2-2-3 律动）内置精巧的诗韵节拍模板，融入八分、四分、附点与二分长音；
  - 在每句诗念唱完的留白小节内，钢琴会自动演奏灵动的**过门加花（Instrumental Fills）**，如同琴声与歌声的一问一答。

### 3. 多轨交织与 Web Audio 物理发声流水线

1. **四轨立体声音响矩阵**：
   - **Lead Melody（主旋律声部）**：`fattriangle` 多振荡器微失谐拨弦，重现古筝与电钢琴融合的灵动木质丝弦共振；
   - **Arpeggio（流水分解和弦）**：`fatsine` 八分音符如山泉滴落，辅以立体声乒乓延迟（Ping-Pong Delay）；
   - **Ambient Pad（空灵背景和声垫）**：整小节长音和声铺底，营造电影级水墨纵深与温暖包围感；
   - **Double Bass（低音托底）**：浑厚扎实的低音，托起古典流行和弦结构。
2. **母带处理声学总线**：
   - 全链路接入动态压限器（`Tone.Compressor`），确保动态紧实不爆音；
   - 注入大音乐厅长混响（`Tone.Reverb`），呈现余音绕梁的空间水墨美学。
3. **ABC 记谱法与实时光标跟随**：
   - 逐句生成标准 ABC 代码（带有完整调号、和弦名、换行连贯排版与精准对齐的歌词行 `w:`）；
   - 基于 `abcjs` 在浏览器中实时渲染矢量五线谱，演奏时乐符与歌词文字同步高亮推进。
4. **标准 MIDI 文件导出**：
   - 基于 `midi-writer-js` 导出包含主旋律、分解伴奏、低音的多轨 `.mid` 文件，无缝导入各主流宿主宿主软件（DAW）。

## 🖥️ 功能全景图

| 模块 | 功能特性 |
| :--- | :--- |
| **诗词灵感胶囊** | 内置《望月怀远》、《鹿柴》、《将进酒》、《春夜喜雨》、《登高》、《水调歌头》一键生成体验 |
| **自由文本输入** | 支持输入任意现代随感或古典诗词，即时提取声律与情感特征 |
| **流行中国风编曲** | 融合羽/宫/商/角五声调式与流行和弦进行，具备“起承转合”完整曲式 |
| **沉浸式多轨演奏** | 包含主旋律、流水分解和弦、氛围和声垫音、浑厚贝斯四大声部 |
| **精准进度同步** | 单行可拖拽进度条，拖拉与时间轴、音频、五线谱唱词瞬时精准对齐 |
| **矢量五线谱查看器** | 基于 ABCjs 渲染高清矢量五线谱，支持一键下载 SVG 图与复制 ABC 源码 |
| **标准 MIDI 导出** | 一键打包并下载标准多轨 `.mid` 文件，供二次编曲创作 |

## 🚀 本地开发与启动

### 环境要求
- Node.js >= 18.0.0
- pnpm >= 9.0.0

```bash
# 1. 安装依赖
pnpm install

# 2. 启动本地开发服务 (支持 HMR 热更新)
pnpm dev

# 3. 生产环境构建打包 (验证通过无报错)
pnpm build
```

访问：`http://localhost:3000`

## ☁️ 部署到 Vercel (推荐)

本项目**没有使用任何专有服务端二进制或付费 API**，天然具备全静态/Serverless 部署能力：

1. 将本项目推送到您的 **GitHub 仓库**；
2. 打开 [Vercel 仪表盘](https://vercel.com/)，点击 **"Add New Project"** 并导入此仓库；
3. Framework Preset 选择 **Nuxt.js**，点击 **Deploy** 即可一键上线！
